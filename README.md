## 🧩 Featured Project

### [Login API v3.0 — Fullstack Authentication Console](https://github.com/yeko0/Login-API-v1)

A learning-focused fullstack authentication project built with **Java 17**, **Spring Boot 4**, **Spring Data JPA / Hibernate**, **JWT**, **BCrypt**, **Javascript**, **React**, **Vite**, **Tailwind CSS**, and SQL databases.

The project combines a REST API backend with a React-based API console for testing authentication, authorization, role-based access, database persistence, frontend guards, request/response handling, and session behavior.

Main features:

* User registration and login
* JWT-based authentication
* BCrypt PIN hashing
* USER and ADMIN role authorization
* Admin-only endpoints
* Account-owner-only endpoints
* Current session validation
* Spring Data JPA persistence
* DTOs and public user projections
* Global validation and exception handling
* React frontend with endpoint cards
* Centralized API request helpers
* Frontend guards for login, admin access, empty inputs and invalid IDs
* Live request/response inspector
* Body, Headers and Payload views
* Copy, clear and token-copy feedback
* Masked PIN and token values in the UI

This project documents my progress from backend fundamentals to a more complete fullstack architecture.
